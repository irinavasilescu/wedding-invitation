# Wedding Invitation

This React-based digital wedding invitation features an elegant, minimalist design combined with custom, hand-drawn illustrations. Designed with clean typography and a muted colour palette, the site delivers event details, including a calendar layout, venue showcase, and integrated RSVP buttons, in a refined, personal aesthetic tailored for a high-end web experience.
